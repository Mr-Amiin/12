About Converting Milliliters per Hectare to Cubic Meters per Square Kilometer

Milliliter per Hectare and Cubic Meter per Square Kilometer both measure a farming-related quantity — a land area or an application/yield rate per unit area — used to report crop yields, calculate how much fertilizer or seed a field needs, and plan irrigation. Both are liquid application rate units.

Formula

cubic meters per square kilometer = milliliters per hectare × 0.0001

This factor comes from each unit's defined relationship to the category's base unit: 1 milliliter per hectare equals 1e-10 base units, and 1 cubic meter per square kilometer equals 0.000001 base units, so dividing one by the other gives the direct milliliter per hectare-to-cubic meter per square kilometer factor of 0.0001.

Simple example

1 mL/ha × 0.0001 = 0.0001 m3/km2

1 milliliter per hectare = 0.0001 cubic meters per square kilometer.

Real-world example

What's the difference between a yield rate and an application rate?

A yield rate describes how much of a crop is harvested per unit of land area (for example, tonnes per hectare). An application rate describes how much of an input like fertilizer or seed is applied per unit of land area. Both are commonly expressed using the same kind of mass-per-area units.
