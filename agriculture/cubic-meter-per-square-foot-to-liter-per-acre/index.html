About Converting Cubic Meters per Square foot to Liters per Acre

Cubic Meter per Square foot and Liter per Acre both measure a farming-related quantity — a land area or an application/yield rate per unit area — used to report crop yields, calculate how much fertilizer or seed a field needs, and plan irrigation. Both are liquid application rate units.

Formula

liters per acre = cubic meters per square foot × 43560000

This factor comes from each unit's defined relationship to the category's base unit: 1 cubic meter per square foot equals 10.7639104167 base units, and 1 liter per acre equals 2.471054e-7 base units, so dividing one by the other gives the direct cubic meter per square foot-to-liter per acre factor of 43560000.

Is the cubic meter per square foot to liter per acre conversion exact?

What's the difference between a yield rate and an application rate?

A yield rate describes how much of a crop is harvested per unit of land area (for example, tonnes per hectare). An application rate describes how much of an input like fertilizer or seed is applied per unit of land area. Both are commonly expressed using the same kind of mass-per-area units.
