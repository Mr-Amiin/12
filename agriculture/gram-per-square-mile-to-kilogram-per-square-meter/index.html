Understanding the Kilogram per Square Meter

Kilogram per Square Meter (kg/m2) measures agricultural application/yield rate, or areal density. A mathematically valid way to express an application rate or areal density in kilograms per square meter. It is classified as a metric derived rate unit.

Uses of the Kilogram per Square Meter today

  • Can be used for application rates or areal density at small scale — for small-garden and turf applications, grams per square meter is the unit more commonly seen in practice, since kilograms per square meter represents a very heavy rate for typical garden or lawn use

Kilogram per Square Meter — sources

  • Garden and turf-care application-rate references — Small-scale application rates are typically expressed in grams per square meter rather than kilograms per square meter.

What's the difference between a yield rate and an application rate?

A yield rate describes how much of a crop is harvested per unit of land area (for example, tonnes per hectare). An application rate describes how much of an input like fertilizer or seed is applied per unit of land area. Both are commonly expressed using the same kind of mass-per-area units.
