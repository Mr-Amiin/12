About Converting Gigabits to Megabits

Gigabit and Megabit are everyday digital-storage units, used for everything from file sizes and app downloads to storage device capacity and mobile data allowances. Gigabit is typically associated with used worldwide for high-speed network ratings (fiber internet, data centers), while Megabit is typically associated with used worldwide for network and internet speed ratings.

Formula

megabits = gigabits × 1000

This factor comes from each unit's defined relationship to the category's base unit: 1 gigabit equals 1000000000 base units, and 1 megabit equals 1000000 base units, so dividing one by the other gives the direct gigabit-to-megabit factor of 1000.

Understanding the Gigabit

Gigabit (Gb) measures digital storage/transfer. A gigabit is 1,000 megabits (125 megabytes) under the decimal convention used for network speeds. It is classified as a Decimal (SI-prefixed) digital unit.

Where it's used: Used worldwide for high-speed network ratings (fiber internet, data centers)

Uses of the Gigabit today

  • Gigabit fiber internet service advertising
  • Data center and enterprise network bandwidth

History of the Gigabit

As internet speeds crossed the 1,000 Mbps threshold with fiber-optic and enterprise networking, 'gigabit' became the standard marketing term for these connections, following the same bits-per-second convention established for slower network speeds.

Historical origin. Gigabit was not the invention of a single named person; it developed through the process described above.

Understanding the Megabit

Megabit (Mb) measures digital storage/transfer. A megabit is 1,000,000 bits (125,000 bytes) under the decimal convention used for network speeds. It is classified as a Decimal (SI-prefixed) digital unit.

Where it's used: Used worldwide for network and internet speed ratings

Megabits vs. megabytes. Internet speeds are quoted in megabits per second (Mbps), while file sizes are quoted in megabytes (MB) — 8 megabits equal 1 megabyte, so a '100 Mbps' connection downloads at up to about 12.5 MB per second.

Uses of the Megabit today

  • Internet connection speed advertising (Mbps)
  • Network bandwidth measurement

History of the Megabit

Network speeds have conventionally been quoted in bits rather than bytes since early telecommunications measured signal rate in bits per second; this convention carried into modern internet service marketing, which is why connection speeds (Mbps) and file sizes (MB) use different base units, a frequent source of consumer confusion.

Historical origin. Megabit was not the invention of a single named person; it developed through the process described above.
