About Converting Megabits to YB

Megabit and YB are everyday digital-storage units, used for everything from file sizes and app downloads to storage device capacity and mobile data allowances. Megabit is most often used for internet connection speed advertising (mbps).

Formula

yb = megabits × 1.25e-19

This factor comes from each unit's defined relationship to the category's base unit: 1 megabit equals 1000000 base units, and 1 yb equals 8e+24 base units, so dividing one by the other gives the direct megabit-to-yb factor of 1.25e-19.

Simple example

1 Mb × 1.25e-19 = 1.25e-19 YB

1 megabit = 1.25e-19 yb.

Real-world example

500 Mb × 1.25e-19 = 6.25e-17 YB

500 megabits = 6.25e-17 yb.

Understanding the Megabit

Megabit (Mb) measures digital storage/transfer. A megabit is 1,000,000 bits (125,000 bytes) under the decimal convention used for network speeds. It is classified as a Decimal (SI-prefixed) digital unit.

Where it's used: Used worldwide for network and internet speed ratings

Megabits vs. megabytes. Internet speeds are quoted in megabits per second (Mbps), while file sizes are quoted in megabytes (MB) — 8 megabits equal 1 megabyte, so a '100 Mbps' connection downloads at up to about 12.5 MB per second.

Uses of the Megabit today

  • Internet connection speed advertising (Mbps)
  • Network bandwidth measurement

History of the Megabit

Network speeds have conventionally been quoted in bits rather than bytes since early telecommunications measured signal rate in bits per second; this convention carried into modern internet service marketing, which is why connection speeds (Mbps) and file sizes (MB) use different base units, a frequent source of consumer confusion.

Historical origin. Megabit was not the invention of a single named person; it developed through the process described above.
